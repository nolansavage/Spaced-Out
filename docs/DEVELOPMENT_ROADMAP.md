# Development Roadmap

## Version 0.1: Playable Foundation

- Canvas world at a 320x180 internal resolution.
- DOM character creation and basic profile saving.
- Four-direction player movement, camera, collision, and starting ship rooms.
- Title, HUD, and pause UI foundation.

Future versions add inventory/farming, repairs/AI, then crafting, combat, travel, NPCs, and story progression in that order.
